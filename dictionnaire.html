1. Mouvements Géométriques
Code Désignation Description
G00 Positionnement rapide Déplacement à vitesse maximale machine, sans usinage. Hors matière
G01 Interpolation linéaire Usinage en ligne droite à l'avance programmée F. Le code G le plus utilisé.
G02 Interpolation circulaire CW Arc de cercle sens horaire. Paramètres : X, Y/Z, I, J/K ou R.
G03 Interpolation circulaire CCW Arc de cercle sens anti-horaire.
G04 Temporisation (Dwell) Arrêt temporaire. G04 P1000 = 1 seconde. Utile pour finition fond de poche. P = ms
2. Plans, Unités et Formats
CodeDésignationDescription
G17 / G18 / G19 Choix du Plan XY (Fraisage standard), ZX (Tournage / plan frontal), YZ (Latéral).
G20 / G21 Pouces / Métrique G21 est le standard millimètres en Europe. G20 pour les ateliers anglo-saxons.
G28 Retour origine machine Retour aux points de référence machine (POM). Toujours précédé d'un point intermédiaire. Sécurité
G90 / G91 Absolu / Incrémental G90 : coordonnées par rapport au zéro pièce. G91 : déplacements relatifs au point courant.

Schéma de référence

Corrections d'outils

La compensation de rayon (G41/G42) permet au programmeur de coder sur le profil exact de la pièce — la commande décale automatiquement la trajectoire du rayon de l'outil. G43 applique la jauge longueur enregistrée dans la table des offsets.

G41 D01 ; comp. gauche, outil 1
G01 X100. F150.
G40 ; annulation obligatoire
3. Corrections d'Outils et Zéros Pièce
CodeDésignationDescription
⚠ Règle de sécurité : annuler G41/G42 avec G40 et les cycles actifs avec G80 avant tout changement d'outil.
G40 / G41 / G42 Comp. Rayon Fraise G40 : annulation. G41 : comp. gauche (fraise à gauche du profil). G42 : comp. droite.
G43 Comp. Longueur Outil Active la correction de longueur outil enregistrée dans la table H. Ex : G43 H01 Z50. Vital
G54 – G59 Zéros Pièce (WCS) 6 origines programmées dans la table des offsets pièce. G54 est l'origine standard. Indispensable sur toute machine moderne.
4. Cycles de Perçage
CodeDésignationDescription
G80 Annulation Cycle Stoppe le cycle de perçage actif. À programmer après la dernière position. Obligatoire
G81 / G82 Perçage Simple / Chambrage G81 : descente directe, remontée rapide. G82 : idem avec temporisation au fond (finition).
G83 Perçage Débourrage (Peck) Descente par passes Q avec retour en haut à chaque passe pour évacuer les copeaux. Trous profonds
G84 Taraudage Rigide Synchronisation parfaite rotation broche / avance axiale. Pas de filet calculé automatiquement via F et S.
G85 / G86 Alésage G85 : montée à avance F (finition alésage). G86 : montée rapide après arrêt broche.
5. Fonctions Auxiliaires (M)
CodeDésignationAction
M00 / M01 Arrêt Prog. / Optionnel Pause pour contrôle pièce ou opération manuelle. M01 ne s'active que si le mode optionnel est ON.
M03 / M04 Rotation Broche ↻ / ↺ M03 : sens horaire (fraisage standard). M04 : sens anti-horaire. Toujours associé à S (vitesse en Tr/min).
M05 Arrêt Broche Arrête la rotation avant changement d'outil ou fin de programme.
M06 Changement d'Outil Déclenche l'ATC (changeur automatique). Ex : T02 M06 — appel outil 2 avec correcteur.
M08 / M09 Arrosage ON / OFF Contrôle le liquide de coupe. M08 en début d'usinage, M09 avant retour outil ou fin.
M30 Fin de Programme Reset complet + retour au début du programme. Ferme tous les modes actifs. Obligatoire en fin de prog.
M98 / M99 Sous-Programmes M98 P.. : appel sous-programme numéro P. M99 : retour au programme principal. → Voir Leçon 6
6. Spécificités Tournage & Avance
CodeDésignationDescription
G96 / G97 Vitesse de Coupe G96 S180 : vitesse de coupe constante à 180 m/min (adaptée au diamètre). G97 S1200 : vitesse fixe en Tr/min. → Leçon 8
G50 Limite Vitesse Maxi Limite les Tr/min max en mode G96. Sécurité Ex : G50 S3000
G94 / G95 Format d'Avance G94 : mm/min (fraisage). G95 : mm/tr (tournage — la valeur F suit automatiquement la broche).
G71 / G72 Cycles Ébauche G71 : ébauche axiale (chariotage). G72 : ébauche frontale (dressage). Définissent automatiquement les passes. → Leçon 8
G76 Cycle Filetage Cycle complet de filetage multi-passes. Définit le pas, la profondeur et le nombre de passes. → Leçon 9
