// G-Code & Programmation
G00 est le déplacement rapide — la machine se déplace à sa vitesse maximale, sans usinage. Il est représenté en pointillés oranges dans le simulateur.

G01 est l'interpolation linéaire — la machine se déplace à l'avance programmée F, en usinant la matière. C'est le code le plus utilisé.

Règle d'or : G00 hors matière, G01 dans la matière.
C'est le "bloc de sécurité" standard Fanuc. Il garantit que la machine est dans un état connu avant de démarrer :

• G21 — Mode millimètres (et non pouces G20)
• G90 — Mode absolu (coordonnées par rapport au G54)
• G40 — Annulation compensation rayon (G41/G42)
• G80 — Annulation cycle de perçage actif

Ces 4 codes ensemble évitent 80% des crashes par état résiduel.
Ce sont deux choses complètement différentes :

G54 définit OÙ est votre zéro pièce (les offsets X/Y/Z mesurés par le régleur).
G90 définit COMMENT vous calculez — en absolu (par rapport au G54) plutôt qu'en incrémental (G91).

Les deux sont complémentaires et généralement utilisés ensemble.
G96 — Vitesse de coupe constante (m/min). La commande recalcule automatiquement les tr/min selon le diamètre. Idéal pour chariotage et dressage.

G97 — Vitesse de rotation fixe (tr/min). Obligatoire pour : filetage G76 (synchronisation du pas), perçage axial, outils tournants.

⚠️ Toujours utiliser G50 S3000 avant G96 pour limiter les tr/min max.
Parce que les cycles de perçage sont "modaux" — ils restent actifs jusqu'à ce qu'on les annule explicitement. Si vous oubliez G80, la machine percera un trou à chaque position X/Y suivante.

Astuce : créez un template de programme avec le G80 déjà inclus après chaque section de perçage. Vous ne l'oublierez plus jamais.
// Simulateur 3D
• Clic gauche + glisser — Orbite (rotation de la vue)
• Scroll molette — Zoom avant / arrière
• Clic droit + glisser — Pan (déplacement de la vue)
• Tactile 1 doigt — Orbite
• Tactile 2 doigts — Zoom par pincement

Les 5 boutons de vue prédéfinie (Dessus, Face, Côté, Iso) permettent d'aller rapidement aux angles standards.
Vérifiez ces points dans l'ordre :

1. Le simulateur supporte les codes G standard ISO — vérifiez que votre code ne contient pas de codes spécifiques à votre machine
2. Chaque ligne doit avoir un code G ou M valide et reconnu
3. Les commentaires doivent être entre parenthèses (commentaire) ou après un ;
4. Essayez le bouton "Exemple" pour voir un programme de référence
5. Le simulateur affiche l'alarme et la ligne en erreur en rouge
Le brut doit être légèrement plus grand que votre pièce finie pour simuler l'enlèvement de matière réel.

En fraisage : entrez les dimensions du bloc brut (longueur × largeur × hauteur).
En tournage : entrez le diamètre brut (plus grand que le diamètre final) et la longueur totale.

Cliquez sur "Appliquer le brut" après chaque modification pour mettre à jour la vue 3D.
