Qu'est-ce que la CNC ?

La Commande Numérique par Calculateur est le cerveau de la machine. Elle interprète des données numériques pour piloter les moteurs avec une précision chirurgicale.

Le Langage G-Code

C'est la liste d'instructions envoyée à la machine. Chaque ligne (bloc) dicte un mouvement ou une action : G pour la géométrie, M pour la machine.

Le Standard Fanuc

Le système Fanuc est la référence absolue en usinage. Apprendre le code ISO Fanuc vous ouvre les portes de 90% des ateliers de mécanique.
