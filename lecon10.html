Programmation
Paramétrée

Le niveau final : apprenez à coder des programmes qui réfléchissent, calculent et s'adaptent. Un seul programme pour mille pièces différentes.

01.

Le Concept des Variables

En programmation standard on écrit X100.0 — une valeur fixe, figée. En paramétré on écrit X#100 — une variable qui peut changer.

Pourquoi utiliser les variables ?
  • • Universalité : Un seul programme pour 100 diamètres différents
  • • Calculs : Trigonométrie directement dans le CNC
  • • Sécurité : Vérifier les valeurs avant d'usiner
  • • Compteurs : Tracer la production pièce par pièce

// Démo — variable en action

Valeur de #100 (diamètre)
#100 = 50.0 ; (diamètre)
G00 X52.0 ; (#100+2 = approche)
G01 X50.0 F0.25 ; (= #100)
; Rayon = 25.0 mm (#100/2)
; Section = 1963.5 mm²

Modifiez #100 — tout se recalcule automatiquement.

02.

Hiérarchie des #Variables

#1 → #33
Locales

Utilisées à l'intérieur d'un seul sous-programme. Effacées à chaque appel M98. Idéal pour les calculs temporaires.

#1 = 10.0 ; temporaire
#100 → #199
Communes

Partagées entre tous les programmes actifs. S'effacent à l'extinction de la machine. Idéal pour passer des données entre programmes.

#100 = 50.0 ; diamètre
#500 → #999
Permanentes

Restent en mémoire même après extinction. Idéal pour les compteurs de pièces, les offsets dynamiques et les recettes.

#500 = #500 + 1 ; compteur
03.

Logique et Calculs

Arithmétique de base

#100 = 50.0 ; affectation
#101 = #100 + 10. ; addition
#102 = #100 * 2. ; multiplication
#103 = #100 / 2. ; division (rayon)

Fonctions avancées

#104 = SIN[45] ; sinus (°)
#105 = COS[30] ; cosinus
#106 = SQRT[16] ; racine carrée → 4
#107 = ABS[#100] ; valeur absolue
04.

Les Boucles WHILE — Automatisation

La boucle WHILE répète un bloc d'instructions tant qu'une condition est vraie. Idéale pour usiner N rainures espacées régulièrement sans répéter le code.

#100 = 0 ; compteur init
WHILE [#100 LT 10] DO 1
  G01 Z-10. F0.2 ; usinage
  G00 Z2. ; retrait
  G00 X[#101 * #100] ; décalage
  #100 = #100 + 1 ; incrément
END 1

05.

Sécurité Anti-Crash — IF / GOTO

⚠️ Vérification avant usinage

Le paramétré permet de forcer l'arrêt de la machine si une valeur incorrecte est détectée — avant même que l'outil ne bouge.

( Vérifie que #100 est raisonnable )
IF [#100 GT 200] GOTO 999
IF [#100 LT 5] GOTO 999
(...programme normal...)
N999 #3000 = 1 (DIAMETRE INVALIDE)
#3000 — Alarme personnalisée

Le code #3000 affiche un message d'alarme sur l'écran Fanuc et coupe instantanément tous les axes. C'est votre bouton d'arrêt d'urgence logiciel.
