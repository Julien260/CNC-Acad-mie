Programmation Structurée · Leçon 06 / 10

M98 / M99
Le Pouvoir de la Répétition

Gagnez en clarté, réduisez les lignes de code et évitez les erreurs de frappe — en appelant un sous-programme plutôt qu'en copiant-collant du code.

Mots-clés de la leçon

M98 P.. — Appel

Ordre de "quitter" le programme principal pour aller exécuter le sous-programme numéro P. Le programme principal attend, suspendu.

M99 — Retour

Point final du sous-programme. Dit à la machine : "C'est fini, retourne à la ligne suivante dans le programme principal."

L.. — Répétitions

Paramètre optionnel pour répéter le sous-programme N fois. M98 P2000 L5 = 5 répétitions de O2000.

G91 — Incrémental

Très souvent utilisé dans les sous-programmes pour que l'outil se déplace "par rapport à sa position actuelle" — indispensable pour les passes successives.

Schéma — Flux d'exécution M98 / M99

Exemple — Usiner 3 rainures identiques

Programme Principal O1000
O1000
T01 M06 ; fraise D10
G00 G90 G54 X0. Y0.
S3000 M03 M08
G43 H01 Z10.

( rainure 1 )
M98 P2000

G00 X0. Y20. ; position 2
M98 P2000

G00 X0. Y40. ; position 3
M98 P2000

G00 Z100. M09 M05
M30
Sous-Programme O2000
O2000 ; déclaration

G01 Z-5. F200. ; plongée
G01 X50. F800. ; usinage rainure
G00 Z2. ; dégagement
G00 X0. ; retour départ

M99 ; retour prog. principal
O2000 contient la séquence d'une rainure. En l'appelant 3 fois, on usine 3 rainures sans dupliquer le code. Si la profondeur change, on modifie juste O2000.

Quand utiliser les sous-programmes ?

🔁

Motif répété

Rainures, poches ou trous identiques à plusieurs positions sur la pièce.

📉

Passes profondes

Descendre en Z par incréments avec L répétitions + G91 Z-1.

📦

Bibliothèque

Sous-programme de changement d'outil ou de palpage, réutilisé dans tous vos programmes.

🎯

Multi-pièces

Même contour usiné sur G54, G55, G56 en changeant juste l'origine entre chaque appel.

💡

L'astuce pro : G91 + L pour des passes en Z

Pour usiner une poche profonde sans surcharger la fraise, appelez votre sous-programme avec un nombre de répétitions L et utilisez G91 (incrémental) à l'intérieur :

( Programme principal )
M98 P3000 L10 ; 10 passes de 1mm = prof. -10mm

( Sous-programme O3000 )
G91 Z-1. ; descend de 1mm relatif
G01 X80. F600.
G01 X0.
G90 ; retour absolu avant M99
M99

⚠️ Toujours revenir en G90 avant M99 pour éviter que le programme principal hérite du mode incrémental !
